# Documentation visuals

These assets describe the implemented Yap workflow and reuse photography and video posters already shipped on the website. The media composition is an editorial overview, not an application screenshot or a sample video generated by Yap.

| Asset                                                           | Format and dimensions     | Purpose                                                                                                                      |
| --------------------------------------------------------------- | ------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| [Website media + workflow overview](website-media-overview.jpg) | JPEG, 1800 × 1120         | A photographic introduction using the site's camera, keyboard, audio, and record-store studies.                              |
| [Architecture diagram](architecture.svg)                        | Editable SVG, 1800 × 1500 | Research delegation, virtual artifacts, evidence analysis, creator review, structural verification, approval, and rendering. |
| [Architecture bitmap](architecture.png)                         | PNG, 1800 × 1500          | The same diagram rendered for consistent typography in documentation previews.                                               |

The specialists execute in dependency order: source researcher, then network analyst, then creative strategist. The graph drawing illustrates the distinction between observed public interactions and derived content similarities. Its generic nodes are not a live dataset. The diagram separates attributed research framing from the creator's own product facts and photos. Structural checks do not establish factual truth or grant approval. Rendering follows explicit approval of the current content version.

The visual identity follows [the application's current tokens](../../apps/web/src/styles.css) and [its social image](../../apps/web/public/social.svg): Manrope, coral, dark ink, and neutral surfaces. The bitmap exports were rendered with Manrope. The editable SVG specifies Manrope with a sans-serif fallback.

## Regeneration

From the repository root, after the normal workspace dependency installation:

```sh
node docs/assets/generate.mjs
```

The generator uses the installed Sharp dependency and the existing website assets. It makes no network calls and does not edit application code, source photos, or source credits. For the same bitmap typography, set `YAP_DOCS_FONT_FILE` to a local Manrope TTF before running it. Manrope's published font source is available in the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/manrope); no font file is redistributed with these documentation assets.
